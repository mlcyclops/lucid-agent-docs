LUCID Agent is a desktop app where AI [agents](/glossary/#agent) do real work on your computer. An agent is an AI helper that can read files, run commands and write things for you, and LUCID checks every action before it runs and asks for your [approval](/glossary/#approval) when it matters.

## What you need

- A computer running Windows (64-bit), macOS (Apple silicon or Intel) or Linux.
- Nothing else to install first. Every LUCID download includes what it needs to run.
- An AI account to chat with: a subscription you already pay for, such as Claude or ChatGPT, or an [API key](/glossary/#api-key). An API key is a secret code a [model provider](/glossary/#model-provider) gives you so an app can use its AI. You add it after you install, so you can start without one.

## The path

<Steps>

1. **Install LUCID.** Pick the page for your computer and download one file.

2. **Open it for the first time.** LUCID asks a few short questions. Each one can be skipped.

3. **Connect your AI.** Sign in with a subscription or paste an API key, so your agents have an AI to think with.

</Steps>
